# Sistema de Gerenciamento de Atividades

Trabalho Final de Desenvolvimento Web, feito com HTML5, CSS3 e JavaScript puro.

## Integrante

- Luan Henrique Ferreira Pinto

## Funcionalidades desenvolvidas nesse app:

- Cadastro de atividades com título, descrição, categoria, prioridade, data limite e situação
- Validação dos campos obrigatórios (título e data limite)
- Listagem dinâmica em tabela, com cores para prioridade e situação
- Edição (o formulário é preenchido com os dados) e exclusão com confirmação
- Pesquisa por título enquanto digita
- Filtros por situação e prioridade
- Ordenação por título, data limite e prioridade
- Estatísticas: total, pendentes, em andamento e concluídas
- Dados salvos no navegador (localStorage), mantidos ao reabrir a página
- Extras: modo escuro e aviso de prazo vencido

## Para executar esse trabalho, siga as etapas:

1. Extraia o arquivo ZIP.
2. Abra o arquivo `index.html` no navegador.
