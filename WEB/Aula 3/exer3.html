Qual a diferença entre linguagem de programação server side e client side?

Característica Client Side Server Side
Onde executa? Executa no dispositivo do usuário Executa no servidor
Principal objetivo Interface e interação Processamento e regras
Exemplos de linguagens HTML, CSS, JavaScript Java, Python, PHP
Velocidade Pode ser imediata, por estar no dispositivo do usuario Depende da comunicação com o servidor
